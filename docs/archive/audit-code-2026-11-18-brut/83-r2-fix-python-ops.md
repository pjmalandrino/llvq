## Décision d'opérateur

- R2-DIF-45, espace de noms : `_is_runner_image` accepte toujours tout `<namespace>/llvq-runner*`. Je recommande de borner à l'espace de noms de l'opérateur (`args.namespace` s'il est donné, sinon une constante `RUNNER_NAMESPACE = "Pier-Jean"`), avec la décision SEC-01 déjà ouverte : le docstring de `_hf_token_secret` promet le jeton « only to the image this repository builds ».
- R2-API-16 et R2-API-03 changent les codes de sortie de `llvqtune` : 1 n'existe plus hors `--repeat-one-batch`, 6 est neuf. `train.sh` lance l'entraînement sous `set -e`, donc un run court fait sortir `train.sh` en 6 ; les préregs listent « exits 2, 3, 4 or 5, or the job dies » comme « no sigma ; stop ». Un 6 tombe dans « the job dies », ce qui est le bon traitement. À nommer dans le prochain préreg qui appelle `train.sh`.

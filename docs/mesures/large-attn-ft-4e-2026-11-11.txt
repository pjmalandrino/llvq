WHICH ATTENTION THE FULL TILE IS ON (read in the code)
----------------------------------------------------
The summary labels 4,096 and 8,192 "the served config ... inside the T8". That label names the eager side's form,
not 4E's. fusedrun (bin/fusedrun.rs, the context loop) sets the eager comparator to the kernel attention from
KERNEL_FROM = 1,280 when the prompt reaches it (the configuration the operator's T8 licensed), and to the kernel on
every row below it (the measurement form). The grouped path it mentions is the eager config's below 1,280.
4E's own attention is the same at every context: pers_attention in llvq_pers.cuh calls pers_attn_tile on every tile
of every split, and v9ft's edit (pers.rs::pers_ft_edit) branches at the head of pers_attn_tile to the full-tile body
when the tile holds 8 positions. At 4,096 and 8,192 every tile of a row but the last is full. So the full-tile path is
on 4E's path at the four contexts.

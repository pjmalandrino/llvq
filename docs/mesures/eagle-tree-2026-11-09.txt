Method : greedy decoding makes acceptance a function of the greedy text. At every round position m the head's cache
         over 0..m-1 is built from the target's states, as eagle-alpha replays a chain; a tree node attends that
         cache and its own ancestors. A tree accepts depth d when x[m+1..m+d] is a path from its root, and the pass
         emits d + 1 tokens. Every position gets its tree in one batched pass; the rounds are then replayed as the
         loop runs them, for every tree.
         - dynamic (EAGLE-2): each level expands the K = 8 candidates of highest cumulative log probability, each
           proposes its top 8; after d levels the N best candidates of all levels form the tree. d head steps a round.
         - static: the N most frequent rank paths of the true tokens over the other five workloads, each weighted
           equally (leave one workload out). Head steps a round: the tree's depth.
Gate   : the chain k = 1, 2, 3 replayed from this script's teacher-forced ranks equals eagle_alpha.py's own replay on
         the same completions, rounds and tokens, at every workload: HOLDS. Both reproduce eagle-alpha-2026-11-08.txt:
         chat 171 / 157 / 151 rounds for 255 tokens, GSM8K 9,596 / 7,615 / 6,938 for 16,817.

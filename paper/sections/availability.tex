\section{Availability}
\label{sec:availability}

The implementation, the CSV files behind every table and figure in this
paper, and the source of the paper itself are at
\ifanon{\url{https://github.com/pjmalandrino/llvq}}{a public repository whose
URL is withheld for double-anonymous review}, dual-licensed MIT or
Apache-2.0. Frozen states are tagged together with their numbers (the submitted
revision will carry its own tag), and \texttt{make} in \texttt{paper/}
refuses to build if a table has drifted from the CSV it is transcribed
from.
The lattice core, the exact nearest-neighbor search and the artifact format
are dependency-free Rust and can be read end to end; \texttt{candle} and
\texttt{cudarc} enter only through the model-side and kernel crates.

The quantized Qwen3-4B artifact is published at
\ifanon{\url{https://huggingface.co/Pier-Jean/Qwen3-4B-LLVQ-2bit}}{a public
model repository whose URL is withheld for double-anonymous review}: both
files behind columns 3 and 4 of Table~\ref{tab:campaign}, the sealed
1.77~GB file and the 1.41~GB one with the int8 embedding pre-baked. The 8B
and 14B artifacts are not published but are reproducible at the costs
recorded in \texttt{docs/\allowbreak data/\allowbreak jobs.csv}; what is
committed for all three sizes is the evidence behind every paired
statistic: the per-question MMLU dumps of all nine arms and the per-window
log-likelihoods behind the nine perplexity intervals, raw and committed
rather than aggregated and cited, since an aggregated log cannot be barred
afterwards and vendor log retention is neither documented nor guaranteed.
No third-party runtime reads the format; the only reader is the
\texttt{llvq-artifact} crate in this repository. Serving additionally
requires the rotation kernel of \S\ref{sec:limitations}, CUDA-only, with
the servable \texttt{intermediate\_size} capped at 25\,344 coordinates:
above the 14B, below the 32B.

An artifact carries its own tokenizer and configuration, so on an NVIDIA GPU
the served configuration of Table~\ref{tab:campaign} and the two evaluations
replay from the file alone, with no checkpoint and no network:

{\small
\begin{verbatim}
LLVQ_FUSED_LAYOUT=planes14 LLVQ_EMBED=q8 cargo run --release \
  -p llvq-llm --features cuda --bin fusedrun -- <artifact>

LLVQ_DTYPE=f16 cargo run --release \
  -p llvq-llm --features cuda --bin ppl -- 4096 12 cuda <artifact>

cargo run --release \
  -p llvq-llm --features cuda --bin mmlu -- <artifact> cuda 40
\end{verbatim}
}

\noindent
\texttt{LLVQ\_FUSED\_LAYOUT} selects the VRAM layout of
\S\ref{sec:layouts}, all four measured points: \texttt{planes14} (the
default),
\texttt{planes12x}, \texttt{slot32}, and \texttt{golay70} (wired to be
measurable, not served), any other value being refused rather than silently
defaulted;
\texttt{LLVQ\_EMBED} selects the embedding precision (\texttt{f16}, the
default, or \texttt{q8}); \texttt{LLVQ\_DTYPE} pins the evaluation dtype,
because \texttt{ppl} defaults to f32 and \texttt{mmlu} to f16. Each binary
prints its resolved configuration and a fingerprint of the scored token
stream; numbers are comparable only when fingerprints match, the discipline
every table in this paper is held to.

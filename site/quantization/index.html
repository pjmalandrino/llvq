LLM quantization, from 16 bits to 2

What quantization does to a model, what 4-bit and 2-bit mean, and what we measured when we went down to about 2.5 bits per parameter.

The size of a model is its bits per weight

A model file weighs about parameters × bits per weight ÷ 8 bytes. Card memory follows the same rule, plus the cache that grows with the prompt.

What it costs

Fewer bits means more rounding error, and the error shows up as lost accuracy. Three Qwen3 models, each measured on all 14,042 MMLU test questions and the 1,319 GSM8K problems:

Questions

What is LLM quantization?

Quantization stores each weight of a model in fewer bits than the 16 it was trained with. The file gets smaller, the model needs less GPU memory, and some accuracy is lost.

What does 2-bit or 4-bit mean?

It is the average number of bits spent per weight. A 4-bit file is about a quarter of the 16-bit model, a 2-bit file about an eighth. Real files land a little above the nominal figure because some tables stay at a higher precision.

Is 2-bit quantization usable?

It depends on the method and on the model size. Measured on Qwen3 with Tetra at about 2.7 bits per parameter: MMLU 63.37 for the 4B, 69.58 for the 8B and 75.66 for the 14B. The loss against 4-bit AWQ shrinks as the model grows, from 4.76 points on the 4B to 2.46 on the 14B.

Is a bigger model at 2 bits better than a smaller one at 4 bits?

On Qwen3 and MMLU, yes at about the same file size: the Tetra 8B scores above the 4-bit AWQ 4B, and the Tetra 14B above the 4-bit AWQ 8B.

What is vector quantization?

Scalar quantization rounds each weight on its own. Vector quantization rounds a group of weights together to the nearest point of a codebook, which wastes fewer bits. Tetra rounds blocks of 24 weights to points of the Leech lattice, the densest known packing in 24 dimensions.

Does quantization need training?

Not always. Post-training methods such as GPTQ, AWQ and Tetra only need a few calibration texts. Quantization-aware training retrains the model and costs far more compute.

How much VRAM to run an LLM locally

Measured card memory for four models at about 2.5 bits per parameter, after a short prompt and after a long one.

Peak card memory on one NVIDIA L40S, batch 1. Qwen3: after 5 and after 8,192 prompt tokens. Inkling 2 Mini: after load and while reading 9,000 tokens. None of these was run on a consumer card; the cards supported are the RTX 40 series and newer.

Questions

How much VRAM do I need to run an LLM locally?

Enough for the weights plus the cache of the prompt. With Tetra files, measured on an NVIDIA L40S: Qwen3 4B peaks at 2.0 GB after a short prompt and 6.0 GB after 8,192 tokens; Qwen3 14B at 5.7 and 10.5 GB; Inkling 2 Mini loads in 8.4 GB and peaks at 12.0 GB reading 9,000 tokens.

Can I run a 14B model on an 8 GB card?

The Qwen3 14B Tetra file holds 5.71 GB after a short prompt, measured on an L40S. A long prompt takes it past 8 GB: 10.54 GB after 8,192 tokens.

Can I run a 26B model on a 16 GB card?

Inkling 2 Mini as a Tetra file peaks at 11.5 GB on an NVIDIA L4 and 12.0 GB on an L40S while reading a 9,000-token prompt. That is under 16 GB, but it has not been run on a 16 GB consumer card yet.

Why does memory grow with the prompt?

The model keeps a cache of keys and values for every token it has read. The weights are fixed; the cache grows with the conversation.
